# Customer-Churn-ML
This project involves developing a machine learning model to predict customer churn using a dataset from the telecommunications industry. Key steps in the process include data observation, cleaning, and visualization, followed by preprocessing and feature engineering to prepare the dataset for analysis. 

The evaluation metrics for the SVM and KNN models indicate a strong performance in predicting customer churn, with SVM achieving an accuracy of 96.90%, an F1 score of 0.90, and a recall of
0.85. KNN also performed well, with an accuracy of 95.59%, an F1 score of 0.85, a recall of 0.76 and an excellent learning curve. Overall, the SVM model demonstrates superior accuracy and F1
score, suggesting it is the better fit for this dataset. Additionally, the PCA visualization reinforces the effectiveness of the SVM model in separating classes
